<h1>Asset Registry Editor</h1>

> [!NOTE]
> **Asset Registry Editor** is an application that allows you to inject or modify the Asset Registry of an Unreal Engine.

<p align="center">

## Features & Improvements
- Automatic Update
- Easy edit file Bin
